# array.c

## 簡単にまとめると
C言語において、巨大な数値（多倍長整数など）を文字列として扱い、**ポインタ（メモリアドレス）**を関数に渡すことで、データをコピーせずに高速に書き換えるサンプルプログラムです。

## 特徴
* **高速な処理（O(1)）**: 文字列全体をコピーせず先頭アドレスのみを渡すため、桁数がどれだけ増えても処理時間は一定です。
* **省メモリ**: 新たな配列メモリを確保せず、元の配列（`big_num`）を直接書き換えます（インプレース処理）。

## 関数仕様

### `void sub(char *p)`
渡された文字列の先頭2文字を `'9'` に上書きします。

* **引数**:
  * `char *p`: 書き換え対象となる文字列の先頭ポインタ（NULL終端されている必要があります）。
* **戻り値**: なし
* **注意点**:
  * 文字の「挿入」ではなく「上書き」を行うため、元の先頭2文字は失われます。
  * 渡す配列は最低でも2文字以上の長さ（終端文字 `\0` を含め3バイト以上）が確保されている必要があります。

### 出力結果
元の文字列の先頭 `"75"` が `"99"` に書き換わって出力されます。
```text
99892375982379826397298359827582470520852762984765924695723985729836596598265982659276597649572693598325
```
